# 🎓 Academic PhD Lead & Faculty Finder

An automated, cloud-native tool designed for prospective graduate students and researchers. It scans a personalized list of target universities, queries the global **OpenAlex Academic Graph**, extracts active Principal Investigators (PIs) and recent publications aligned with your specific research topics, and delivers matching lab profiles and updated tracking files directly to your **Telegram** chat.

Runs **100% free** via **GitHub Actions** on a daily schedule (or on-demand) without requiring local servers, API subscriptions, or residential VPNs.

---

## 📌 Features

* **Automated Scholarly Matching:** Queries OpenAlex for recent high-impact works (2023–2026) associated with designated target institutions.
* **Hierarchical Research Domains:** Supports multi-tier and multi-field keyword groups (e.g., Hardware Acceleration, Embedded AI, Computer Vision, Signal Processing, Communications).
* **Batch Processing:** Scans universities in controlled batches (default: 5 per cycle) to ensure rate-limit compliance and prevent information overload.
* **Instant Telegram Alerts:** Sends structured HTML alert cards containing the professor's name, institution, recent paper title, publication year, and scholarly profile link directly to your phone.
* **Bi-directional Spreadsheets:** Automatically updates your `.xlsx` / `.csv` tracking file with newly discovered PIs and sends the updated spreadsheet as a downloadable attachment in Telegram.
* **Zero Local Footprint:** Scheduled via GitHub Actions cron jobs—your computer stays off.

## 🚀 Quick Setup Guide

### 1. Fork or Clone the Repository

Click the **Fork** button at the top right of this repository to create your own copy on GitHub.

```bash
git clone https://github.com/<your-username>/phd-lead-finder.git
cd phd-lead-finder

```

---

### 2. Configure Telegram Credentials

The bot uses the Telegram Bot API to send alerts and file attachments.

1. **Obtain Bot Token:**
* Open Telegram and message [@BotFather](https://t.me/BotFather).
* Send `/newbot`, follow the prompts, and copy the provided `API Token` (e.g., `7891234567:AAH...`).


2. **Find Your Numeric Chat ID:**
* Message [@userinfobot](https://t.me/userinfobot) on Telegram and send `/start`.
* Copy the numerical `Id` returned (e.g., `123456789`).


3. **Initialize the Bot:**
* Open your newly created bot in Telegram and tap **Start** (bots cannot send unsolicited messages until initialized).



---

### 3. Add GitHub Secrets

1. Go to your repository on GitHub.
2. Navigate to **Settings** $\rightarrow$ **Secrets and variables** $\rightarrow$ **Actions**.
3. Click **New repository secret** and add the following two keys:

| Secret Name | Description / Value |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | The bot token generated by `@BotFather` |
| `TELEGRAM_CHAT_ID` | Your numeric user ID from `@userinfobot` |

---

### 4. Enable Workflow Write Permissions

GitHub Actions needs write access to commit the updated tracking spreadsheet back to your repository:

1. In your repository, go to **Settings** $\rightarrow$ **Actions** $\rightarrow$ **General**.
2. Scroll down to **Workflow permissions**.
3. Select **Read and write permissions**.
4. Click **Save**.

## 🛠 Customization: Keywords & Universities

### 1. Define Your Target Universities

Add your institutions to `List of emails.xlsx` or `List of emails.xlsx - Sheet1.csv` under the column named `University`.

* Keep rows you haven't checked yet clean or set `Checked_General?` to `NO`.
* You can mix raw names, English names, or ranking suffixes (e.g., `Technical University of Munich`, `ETH Zürich`, `Aalto University`); the built-in parser sanitizes university strings automatically.

---

### 2. Customize Your Research Keywords

Open `find_professors.py` and modify the `SEARCH_GROUPS` list to match your own field, degree, or thesis topics:

```python
# ==============================================================================
# DEFINE YOUR FIELD TAXONOMY HERE
# ==============================================================================
SEARCH_GROUPS = [
    (
        "Robotics & Control",
        [
            "reinforcement learning robotics", "quadruped locomotion",
            "manipulation planning", "optimal control theory", "ROS2 trajectory"
        ]
    ),
    (
        "Biomedical Imaging",
        [
            "medical image segmentation", "MRI reconstruction deep learning",
            "diffusion models ultrasound", "histopathology classification"
        ]
    ),
    (
        "Edge AI & Embedded Systems",
        [
            "TinyML", "FPGA neural network accelerator", "hardware-aware neural architecture",
            "low-power digital systems", "VHDL accelerator"
        ]
    )
]

```

> **Tip:** Keep keyword phrases specific and use standard IEEE/ACM/academic terms (3 to 6 keywords per category) for highest lead precision.

## ⚙️ How It Runs

### Automatic Execution

The workflow runs automatically once every 24 hours at `08:00 UTC` via GitHub Actions (`.github/workflows/find_profs.yml`).

### Manual Trigger (On Demand)

Whenever you want to fetch the next batch immediately:

1. Open your repository on GitHub.
2. Go to the **Actions** tab.
3. Select **Discover Professors (Daily Batch of 5)** from the left sidebar.
4. Click **Run workflow** $\rightarrow$ select branch `main` $\rightarrow$ click the green **Run workflow** button.

Within 15–30 seconds, your Telegram bot will deliver the matched faculty cards and updated tracking spreadsheet.
